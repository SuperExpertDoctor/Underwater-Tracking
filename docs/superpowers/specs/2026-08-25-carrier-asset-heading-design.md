# 航母图标航向校正设计

## 目标

使态势地图上的航母图片舰艏与仿真输出的 `heading_rad` 一致：`0` 指向东（屏幕右方），`π/2` 指向北（屏幕上方）。

## 根因

`aircraft-carrier.png` 的舰艏实际朝左，但 `CanvasMap` 把它当成朝上，并采用 `π/2` 的资源旋转偏移。因此每个航向显示时都额外偏转 90°。

## 方案

仅更新前端资源旋转基准：

- 将 `CARRIER_ASSET_HEADING_OFFSET` 从 `π/2` 调整为 `π`。
- 保留现有的屏幕坐标转换 `-headingRad`，不改变仿真、配置或航向单位。
- 更新 `CanvasMap` 单元测试，分别断言 0 和 `π/2` 的资源旋转，以防止偏移回归。

## 边界与验证

不改动潜艇、UUV、母舰的选择逻辑、仿真状态或路线规划。运行 CanvasMap 单元测试和 UI 构建验证；运行中的 Vite 开发服务器将自动加载该前端变更。
