# 系统总目标与验收可检验项

## 1. Purpose

本规格将算法核心功能凝练为一条系统级 goal，并把每个功能板块落实为
"功能阐述 + 验收可检验项"：功能阐述说明各板块做什么、如何运转，
验收可检验项给出可观测的达标判定条件，作为实现与验收的统一基线。

## 2. Goal（系统总目标）

在敌我动态博弈背景下，依托多层记忆机制持续感知态势演变，依据实时态势、
现有资源与资源使用调度规则滚动制定并自适应修正鲁棒跟踪方案；保证全部
运动实体与航母编队运动严格满足物理/运动学约束，指挥界面全功能稳定运行，
形成"态势感知 → 方案制定 → 校验提交 → 效果回验"的人机协同闭环。

## 3. 功能阐述与验收可检验项

### 3.1 鲁棒跟踪方案的动态制定

功能阐述：

- 以"规划周期 + 事件驱动"双轨运行：每个规划周期滚动生成方案，同时监听
  态势/资源/对抗事件；事件经确认门控合并为战略级重规划触发（如目标意图
  假设仅在标签变化且有证据支撑时确认）。
- 方案生成链路为：意图分析 → 轨迹预测 → 区域生成与策略 → 语义校验 →
  资源优化 → 方案校验 → 提交，任一环节不过即回退修正，保证提交方案的
  语义与资源双重合格。
- 重规划按区域粒度执行（区域级重规划/重验证），不全量重算，保证动态
  修正的时效。

验收可检验项：

- 每个规划周期均有经校验后提交的方案，提交方案硬约束冲突为 0；
- 事件触发重规划后，新方案在限定周期内提交，事件→方案→决策证据在
  ledger 中完整可溯源；
- 意图确认仅接受标签变化且置信度达标的假设（provenance 可审计）。

### 3.2 资源与调度规则符合

功能阐述：

- 资源分配建模为容量约束指派问题（Hungarian 分配），区域容量上限、
  部署可行性、编组锁定、禁用/回收指令均作为硬约束进入优化目标。
- 方案提交前执行资源重验证：资源需求 ≤ 当前可用，超配或冲突即拒绝提交。
- 运行期资源预留登记，防止并行方案之间资源超售。

验收可检验项：

- 任一提交方案资源需求 ≤ 当前可用资源；无超容量分配；
- 无违反锁定编组、禁用/回收指令的执行记录。

### 3.3 多层记忆机制

功能阐述：

- 短期记忆维持当前会话与规划上下文的连贯；长期记忆流经嵌入检索 +
  重排序注入规划与问答上下文，支撑跨周期的态势演变感知。
- 每条记忆绑定证据溯源（事件/决策/知识/方案/会话来源 ID），注入前先
  回验来源有效性，验不过显式标记 DEGRADED。
- 记忆对前台链路非阻塞：LLM 不可用时前台方案生成与问答照常进行，记忆
  工作转入异步队列补写。

验收可检验项：

- 每轮会话产出记忆条目且证据溯源完整可回验；
- LLM 不可用时记忆状态显式标记 DEGRADED 且前台链路不受阻塞；
- 异步记忆补写完成后流游标一致，无丢失、无重复。

### 3.4 敌我动态博弈

功能阐述：

- 对抗图模拟敌方策略生成对抗事件（敌方意图、部署变化），情报报告汇入
  统一事件流；
- 我方对敌方意图假设做反事实推演，评估方案在敌方不同策略下的鲁棒性，
  脆弱处驱动方案修正；
- 敌方策略变化经事件合并进入区域重规划链路，形成博弈闭环。

验收可检验项：

- 敌方策略/意图变化生成对抗事件并进入我方方案修正链路；
- 博弈推演输出含模型出处与置信度记录，分支决策可回放审计。

### 3.5 物理/运动学约束

功能阐述：

- 确定性轨迹预测为每个目标给出估计航迹，作为规划输入；
- 路线规划在网格边界内进行并避开禁区；全部运动实体与航母编队的运动
  更新满足转弯半径、速度等运动学约束；
- 约束校验贯穿"预测 → 规划 → 仿真"全链路，规划输出不允许出现不可行
  机动。

验收可检验项：

- 仿真回放全时段抽样校验，无违反转弯半径/速度约束的采样点；
- 规划路线不含禁区格，全部轨迹落在有效运动范围内。

### 3.6 UI 界面功能

功能阐述：

- 指挥界面覆盖全流程面板：态势（雷达/目标列表）、方案（时间线/Gantt、
  区域视图）、审核（方案预览/确认）、会话（目标与约束指令）；
- 指令闭环：指挥员输入目标/约束 → LLM 解析 → 结构化预览 → 人工应用 →
  方案更新全程界面可见；
- 直播与回放共用同一套呈现与验收口径。

验收可检验项：

- 各面板正常渲染、交互无异常，指令闭环全流程可用；
- 直播与回放验收通过（对齐 docs/verification/main-live-battle-acceptance.md
  口径）。

## 4. Non-goals

- 水动力潜艇模型或完整海洋传播仿真；
- 端到端学习式分配策略；
- 允许 LLM 自行发明坐标、平台 ID 或不可行的通信路径。
